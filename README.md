# Fast Harness

**📄 Read the report → https://fastharness.github.io/**

An experience-accumulating control layer for VLA robot policies. It learns which
teacher (GPT-6) reviews are safe to skip, so repeated tasks get **faster and
cheaper over time** without losing task success — while bounded recovery keeps
safety intact when something goes wrong.

Across four tasks × 20 episodes: **GPT-6 calls −55% to −75%**, **tokens −64% to
−74%**, **wall-clock down to ~⅓ of the first run**, success rate held or improved.

The full write-up — method, mechanisms, figures, and video — is the single-page
report linked above.
